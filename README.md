## Project Overview

Drip Cloud is a streetwear brand from South Africa that was built as part of the Web Development coursework. This repository holds a multi‑page shop that moves Drip Cloud from selling on social media to having a clear, professional and easily reachable website.

The website gives visitors details about Drip Cloud and its products. Lets visitors send enquiries and find contact information.

## Repository Structure

The project is arranged into the following files and folders:

* `index.html` – Home page of the Drip Cloud website.

* `pages/` – Contains the About Us, Products, Enquiry, Contact Us and Thank You pages.

* `css/` – Contains the website styling files.

* `js/` – Contains JavaScript files used by the website.

* `image/` – Contains the background and product images used on the website.

* `wireframes/` – Contains the website wireframe images created during the planning stage.

* `README.md` – Contains information about the project, setup instructions and references.

* `Current Website Analysis.docx` – Contains the analysis of the existing website/business presence.

* `DripCloud_Part1_New_Wireframes_with_Comments.docx` – Contains the Part 1 wireframes and related comments.

## Design & Styling

### Layout Structure

The website has a layout with a decorative background and a separate area for content making information easy to find.

### Colour Palette

The website uses accent colours across the main pages:

* **Homepage:** Purple

* **Products Page:** Red

* **About Page:** Blue

* **Enquiry Page:** Orange

* **Contact Page:** Green

The colour system helps distinguish the sections of the website while maintaining the Drip Cloud brand identity.

## Website Pages

The website contains the pages listed below:

* **Home** – Introduces Drip Cloud brand.

* **About Us** – Gives information about Drip Cloud brand.

* **Products** – Shows the products.

* **Enquiry** – Lets visitors submit product and size enquiries.

* **Contact Us** – Provides contact information.

* **Thank You** – Confirms submission of an enquiry.

## How to Run Locally

1. Clone the repository to your computer:

```bash

git clone https://github.com/vincentjonas065/DripCloud-website.git

```

2. Open the project folder in Visual Studio Code.

3. Use the Live Server extension or index.html` directly in a modern web browser.
